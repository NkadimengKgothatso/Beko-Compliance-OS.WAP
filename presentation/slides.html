App Walkthrough — Features

Compliance Centre

🔒 POPIA Readiness Checklist

12-item checklist across accountability, processing limitation, security, consent, breach response, and more. Progress bar tracks readiness percentage. All changes saved to Supabase in real-time.

📅 SARS Tax Calendar

Deadline table loaded from Supabase. Filter by PAYE/UIF, VAT, Provisional Tax, CIPC/Annual. Status badges show Overdue, Due Soon, or Upcoming.

🏢 CIPC Annual Return Reminder

Set registration date, configure reminder days, add notes. Auto-calculates next filing window and shows countdown.

📁 Document Vault

Drag-and-drop file upload to Supabase Storage. View, download (signed URLs), and delete documents. Supports PDFs, images, spreadsheets, and Word docs.

10

App Walkthrough — Supporting Features

Notifications, Consultation & Profile

🔔 Notifications Centre

Backend-driven compliance alerts with read/unread state. Click to mark as read. "Mark all read" button. Channel toggles for WhatsApp, Email, and SMS. Sample notifications seeded for new users.

📞 Consultation Booking

Book consultations with partner law firms. Select type, preferred date, and add a message. Requests saved to Supabase. View consultation history with status tracking (pending, confirmed, completed).

👤 Profile & Settings

View business details from company profile. Edit full name, phone, and website. Notification preferences and document status at a glance.

⚙️ Admin Panel

Role-based access (is_admin flag). Three tabs: Manage Tenders (CRUD operations), Broadcast Notifications (to individual users or all), and Update Consultation Statuses. Non-admin users see an "Access Denied" page.

Technical Overview

Tech Stack & Architecture

FrontendVanilla HTML / CSS / JavaScript (ES Modules)
AuthenticationSupabase Auth (email/password + OTP + Google OAuth)
DatabaseSupabase PostgreSQL with Row Level Security
File StorageSupabase Storage (document vault)
HostingVercel (static deploy)
PWAService worker, manifest, offline caching
PDF GenerationjsPDF (client-side)

Database Tables (12 tables)

profiles • company_profiles • consultations • notifications • tenders • tender_alerts • tender_tracks • aml_screenings • popia_checklists • tax_deadlines • cipc_reminders • documents

Security

Row Level Security (RLS) on all tables. Users can only read/write their own data. Admin policies use an is_admin() helper function.

PWA Features

Install to home screen, offline app shell caching, themed status bar, Apple mobile web app meta tags.
